A note from Heidi

Keith,

I grew up around dirt bikes. My dad raced professionally, got picked up by Suzuki, and won the Blackwater 100 in West Virginia more than once. My uncle wrote the scoring software for amateur races, so I spent my childhood working amateur races, local and national, and every year at Loretta Lynn's in Tennessee.

So I know how much goes into a race weekend, and how often a track owner gets asked "are you open?"

These days I do marketing for a living: brands, websites, and getting businesses to show up when people ask Google or ChatGPT where to go. Pineville is one of the closest tracks to Charleston, riders clearly love it, and right now the only way to know if it's open is to scroll Facebook. So I built the website I think it deserves.

The rest of this page walks through it.

01 · The problem

Riders can't tell when you're open

Pineville has a great reputation. The trouble is that every useful fact is in a Facebook post, a comment reply, or a directory that's out of date.

No website

Search for the track and you get directories, Facebook and TikTok. One directory even lists Pineville in New Jersey.

04 · Keeping it current

About ten seconds a week

A website is only useful if it's right. This one is set up so Keith barely has to think about it.

Keith, on his phoneFlip the switch

05 · Getting found

Built for Google and ChatGPT

Behind each page is structured info that search engines and AI tools read directly: address, hours, prices, and every ride day as an event.

Example AI answer, with the site live
Is there a motocross track open near Charleston this weekend?
Yes. Pineville MX Park in Pineville, SC, about an hour from Charleston, has open practice Saturday. Gates open at 10 AM. Practice is $20 per rider, $15 for 50cc.Source: Pineville MX Park official site

Today

AI tools piece the answer together from directories that disagree on prices and say "call ahead."

With the site

The answer comes from Pineville itself, and it's current every time Keith flips the switch.

The example answer is illustrative. Results build over a few weeks as search engines pick up a new site.
